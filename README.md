# Gesture Camera Filter

A hand gesture-based camera filter project using MediaPipe and OpenCV.

## Project Goal

The goal of this project is to recognize hand gestures and shapes in real time and use them to trigger different camera filters and visual effects.

Example:

- Triangle gesture → Comic filter
- Open palm → Original camera
- Other gestures → Different visual effects

## Current Progress

### Week 1
- OpenCV webcam input
- Camera mirroring
- Basic image filters
- Clock display

### Week 2
- MediaPipe Hand Landmarker
- One-hand and two-hand tracking
- 21 hand landmarks
- Fingertip tracking
- Left/right hand detection

### Week 3
- Simple gesture recognition
- Gesture-based filter switching
